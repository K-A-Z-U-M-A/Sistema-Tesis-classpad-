## 1. HERRAMIENTAS UTILIZADAS

"JavaScript es un lenguaje de programación que los desarrolladores utilizan para hacer páginas web interactivas. (Microsoft, 2024)

### Herramienta de Construcción

El proyecto utiliza Vite como herramienta de construcción y servidor de desarrollo.

"Vite ha emergido como una herramienta de construcción líder para proyectos React en 2024, ampliamente reconocido por su velocidad, eficiencia y experiencia de desarrollador mejorada en comparación con alternativas tradicionales como Create React App. Vite aprovecha los módulos ES nativos (ESM), permitiendo que el navegador cargue módulos de forma independiente durante el desarrollo. ## 7. BACKEND - AUTENTICACIÓN Y SEGURIDAD

### Passport.js con Google OAuth 2.0

Se integrará la API de autenticación de Google para permitir inicio de sesión seguro mediante cuentas de Google, garantizando protección contra amenazas como CSRF y manejo de tokens JWT.

"Implementar la autenticación Google OAuth 2.0 con Passport.js en 2024 implica varios pasos clave, enfocándose en configurar tanto la aplicación como la Consola de Desarrolladores de Google para habilitar inicios de sesión seguros de usuarios. Este proceso típicamente utiliza la estrategia passport-google-oauth20 para aplicaciones Node.js. Antes de integrar con Passport.js, necesitas crear un proyecto en la Consola de Desarrolladores de Google, donde obtendrás tu Client ID y Client Secret, que son cruciales para que tu aplicación se comunique con los servicios OAuth de Google. Las API de Google utilizan el protocolo OAuth 2.0 para la autenticación y la autorización, admitiendo los escenarios comunes de OAuth 2.0, como los de aplicaciones web, aplicaciones instaladas en computadoras de escritorio y dispositivos, y aplicaciones del lado del cliente." (Passportjs.org, 2024; Google, s.f.)

**Paquetes utilizados:**
- passport: ^0.7.0
- passport-google-oauth20: ^2.0.0
- passport-local: ^1.0.0

## 9. APIS Y SERVICIOS

### Firebase SDK

Plataforma de desarrollo de aplicaciones de Google que proporciona servicios backend como autenticación, base de datos en tiempo real, almacenamiento y hosting.

> **NOTA IMPORTANTE:** Firebase está instalado en el proyecto pero **NO está siendo utilizado activamente** en la implementación actual. Los archivos de configuración existen (web/src/config/firebase.ts y web/src/firebase/config.js) pero ningún componente de la aplicación los importa o utiliza. "El Firebase JavaScript SDK v10 introdujo varios cambios importantes, particularmente relacionados con el bundle de React Native para autenticación y cambios de tipado en varios productos. En este proyecto, Firebase fue configurado inicialmente para:
- Firebase Authentication: Gestión de usuarios y autenticación segura
- Cloud Firestore: Base de datos NoSQL flexible, escalable y en la nube
- Firebase Storage: Almacenamiento de archivos robusto y seguro para contenido generado por el usuario
